## Writes, builds and recovery

Nine configurations, five iterations of six representative direct SQL statements: game insert/date+score correction, ownership drop/acquire and transaction insert/apply. These are **statement probes, not canonical whole-workflow acceptance**. Each iteration validates inserted/updated state and rolls back; final pending state is checked. Savepoint rollback leaves physical/cache/dead-entry effects, so differences are not precise per-index causal costs.

At1000, member covering index adds7.86MiB; representative ownership acquire WAL280→376bytes and drop371→448bytes on average. Game correction WAL103→372bytes with game index; transaction insert231→327bytes with either full history alternative, versus303with sparse pending partial. Combined structures add costs. Values are EXPLAIN statement WAL, not global LSN attribution or a production durability/vacuum model. Raw probes retain timing/buffers/WAL for every statement; fixed configuration order and physical-state differences are disclosed.

Native concurrent build completed valid/ready; a controlled RowExclusive blocker was observed through `pg_stat_activity` Lock wait, then a2second build timeout left a real invalid residual. Exact owned OID/name/nonconstraint recovery removed it concurrently, then valid rebuild/drop restored baseline catalog. Local concurrent build was about89ms; this is **not** a production build-duration or lock-budget prediction.

Ownership proposal cases cover missing metadata, clean create/verify/recovery, equivalent same/different names, constraint-backed equivalent/different-name skip, same-name constraint drift, wrong definition, native invalid residual, and renamed receipt refusal. Negative cases must produce an intended REFUSE diagnostic and nonzero PostgreSQL-client exit, not an unrelated tool failure. Recovery accepts only same-session newly-created OID/definition receipts after explicit operator review; existing equivalents never get receipts. Failed builds without a receipt require separately reviewed ownership proof, not blind cleanup.
