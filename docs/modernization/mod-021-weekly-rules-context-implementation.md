# MOD021 weekly rules context — 2026-11-16

Supplied-connection weekly scoring now resolves league rules once, after the existing week/final-period and member guards. A private frozen context defensively copies scalar rules and checks league/week/connection identity. Member differentials and biggest-margin fallback receive that same mapping explicitly. Context is never cached on a service, connection or module; each call/retry resolves anew. ScheduleReadService supplies the named same-connection resolver.

The public scorer signature and no-connection path remain unchanged. Raw H2H, game/member SQL, fallback rereads, ownership windows, tier/unranked/phase calculations, late Week lock and atomic score replacement are unchanged. Rules alone are held for the call; this is not a whole-input snapshot. No new lock/isolation/index/schema/provider/HTTP policy.
