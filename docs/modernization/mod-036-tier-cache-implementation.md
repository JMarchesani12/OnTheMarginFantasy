# TypeScript tier-cache recovery — 2026-11-16

The tier loader validates JSON syntax and an events array before publishing a cache entry. A valid empty array remains a cache hit. Invalid legacy content is removed at its exact cache path and gets one normal fetch; malformed recovery throws, while invalid-schema recovery keeps the existing warning/return contract and publishes nothing. HTTP503 still warns/returns empty without automatic retry; network rejection still propagates.

Valid payloads publish via a unique same-directory exclusive temporary file and rename. Only the owned temporary file is cleaned up. Read/I/O errors propagate without invalidating the entry or fetching. Cache keys, TTL/provider limits/timeouts, CLI outputs, Python ingestion and transport policies are unchanged.
