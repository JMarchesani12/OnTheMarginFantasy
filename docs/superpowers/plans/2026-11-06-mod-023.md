# MOD-023 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish all committed draft transitions and converge authorized clients after reconnect.
**Architecture:** Transaction-local PostgreSQL wakeups; one guarded socket recipient boundary; one serialized HTTP refresh controller for the page.
**Tech Stack:** Python/Flask-SocketIO/SQLAlchemy/PostgreSQL, React/TypeScript/Socket.IO.
**Spec:** docs/superpowers/specs/2026-11-06-mod-023-design.md

## Global Constraints

Keep existing event shapes and member-only access. No schema/dependency change, durable replay, configured runtime, deployment, push or commit. Use this existing audit checkout. Listener recovery remains MOD-024.

## Review Focus

- Identity/session revoked between snapshot construction and emit must fail closed.
- All direct and listener paths must use recipient checks, including absent registration.
- Disconnect, scope/token change and denial must invalidate outstanding reads.
- Action responses and storage must not override authoritative empty snapshots.
- Event bursts and late reads must remain serialized without retry loops.
